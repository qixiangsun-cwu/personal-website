常量与变量

怎么让电脑记住数据 · 变量是贴在值上的便利贴

1. 核心概念

  • 常量：不需要改变也不能改变的字面值，例如数字常量 3、3.5。
  • 变量：指其值可以改变的量。程序中使用变量来保存要处理的各种数据，即存储程序执行过程中的信息。
变量的创建：变量是通过赋值方式创建的，并通过变量名标识。格式：变量名 = 值。程序代码按照书写顺序依次执行，所有变量必须先定义后使用，否则会输出报错信息。

3. 变量的存储

  
Python语言中的变量存储的是其值在内存的地址。赋值语句的执行过程：首先把等号右侧表达式的值计算出来，然后在内存中寻找一个位置把值存放进去，最后创建变量并指向这个内存地址。变量的值是可以改变的——重新赋值时，变量会改指向新的内存位置。

  

    

      
x = 3：内存中存放 3，变量 x 指向它

      
x → 3

    

    

      
x = 6：内存中存放 6，变量 x 改指向它（3仍在内存中）

      
x → 6

5. 例题：例2-1 员工月薪计算（变量与常量）

  
假设一个员工每小时的工作薪酬为50元，每天工作8小时，每月工作22天。计算其每月薪酬为多少？如果每小时薪酬上调为80元，每月薪酬又是多少？

    AI渗透 · AI-01变量 = 模型参数

    AI的学习，本质就是一大堆变量不断被重新赋值。w 是模型参数（就是一个变量），每次根据误差调整 w，就是一次学习。GPT有几千亿个这样的 w。全程没有循环、没有AI库，只有赋值 + 算术。
  

  

    
AI训练最小演示：一个参数 w 的学习（梯度下降的本质）
      
    


# AI训练最小演示：一个参数w的学习
x, y_true = 2.0, 10.0
w = 1.0        # 初始猜测
lr = 0.1       # 学习率

# 第1次学习：预测 - 误差 - 调整w
pred = w * x
w = w - lr * (pred - y_true) * x
print(w)       # 2.6

# 第2次学习
pred = w * x
w = w - lr * (pred - y_true) * x
print(w)       # 3.56

# 第3次学习
pred = w * x
w = w - lr * (pred - y_true) * x
print(w)       # 4.136

# 正确答案 w = 5.0（因为 5*2=10）
print("正确答案 w = 5.0")

    
程序输出

  

  
核心洞察：AI的学习 = 变量 w 被反复赋值。没有循环、没有AI库，只有赋值 + 算术。思考：如果学习率 lr 太大或太小，会发生什么？

运算符与表达式

      
怎么让电脑算题目 · 算术/关系/逻辑/赋值/成员

    

  


  
1. 基本概念

  
    
    
  • 运算符是表示对象行为的一种形式。Python支持算术运算符、关系运算符、逻辑运算符以及位运算符，还有特有的运算符，如成员测试运算符、集合运算符、同一性测试运算符等。有些运算符对于不同的对象具有不同的含义（如 + 对数字是相加，对字符串是拼接）。
    • 
    
  • 表达式：运算符、操作对象及其他语法元素的组合，通过运算产生一个确定的值。
    • 
    
  • 运算符优先级：算术运算符的优先级最高，其次是位运算符、成员测试运算符、关系运算符、逻辑运算符等。为避免优先级错误，最好使用圆括号 () 显式指定优先级，同时也能提高代码的可读性。
    • 
  


  
2. 算术运算符

  

    

      
运算符名称示例说明

*乘7 * 2 = 14数值相乘，字符串重复

7. 运算符优先级

  
表达式中运算符优先级的规则为：算术运算符的优先级最高，其次是位运算符、成员测试运算符、关系运算符、逻辑运算符。为了避免优先级错误，最好使用圆括号 () 显式指定优先级，同时也能提高代码的可读性。

  

    

      
优先级运算符说明

      
        
1（高）**幂运算

        
2* / // %乘、除、整除、取余

        
3+ -加、减

        
4== != > < >= <=比较（关系）运算

        
5not逻辑非

        
6and逻辑与

        
7（低）or逻辑或

      
    

  

  

    
演示：运算符优先级与括号
      
    


# 先乘除后加减，幂最高；加括号最稳妥
2 + 3 * 4       # 先算 3*4，再 +2
(2 + 3) * 4     # 括号显式指定优先级
2 ** 3 ** 2     # 幂运算从右向左结合：2**9
(2 ** 3) ** 2   # 加括号后：(2**3)**2

最佳实践：复杂表达式一律加括号，不要依赖记忆优先级。代码是写给人看的，顺便让机器执行。


  

    AI渗透 · AI-02/03神经元 = 加权求和 + 阈值

    AI最核心的代码只有加减乘除：神经元 = 加权求和 y = w1*x1 + w2*x2 + w3*x3 + b，权重不同 = 模型不同 = 判断标准不同。置信度就是 float 表示的概率 + 阈值判断（prob > 0.5 → 是猫）。
  

  

    
神经元计算演示：加权求和 + 激活 + 阈值判断
      
    


# 神经元计算演示
# 输入：耳朵尖度、胡须长度、眼睛颜色
x1, x2, x3 = 0.9, 0.7, 0.8
# 权重（模型学到的参数）
w1, w2, w3 = 0.5, 0.3, 0.2
b = 0.4

# 神经元 = 加权求和
y = w1 * x1 + w2 * x2 + w3 * x3 + b
print(f"加权和 = {y:.3f}")

# sigmoid激活函数 → 概率
import math
prob = 1 / (1 + math.exp(-y))
print(f"是猫的概率 = {prob:.2%}")

# 阈值判断
print("判断：", "是猫" if prob > 0.5 else "不是猫")

    
程序输出

  


  

    AI渗透 · AI-04规则引擎 = and / or / not

    在深度学习之前，AI的核心是规则引擎——用 and/or/not 组合条件来做决策。即使在今天，很多AI系统的前置过滤仍然是规则引擎。
  

  

    
规则引擎：贷款审批AI（组合简单条件表达复杂规则）
      
    


# 规则引擎：贷款审批AI（早期AI的核心逻辑）
def loan_approve(age, income, credit_score, has_job):
    # 规则1：年龄必须在18-65岁
    age_ok = (age >= 18) and (age <= 65)
    # 规则2：有工作 且 月收入 > 5000
    income_ok = has_job and (income > 5000)
    # 规则3：信用分 > 600
    credit_ok = (credit_score > 600)
    # 最终决策：所有条件都满足
    approve = age_ok and income_ok and credit_ok
    return approve

# 这就是 and/or/not 的力量——组合简单条件表达复杂规则
result = loan_approve(25, 8000, 700, True)
print("审批结果：", "通过" if result else "拒绝")

    
程序输出

数据类型

      
数字·字符串·布尔 · 类型转换与浮点精度陷阱

    

  


  
1. 数据类型总览

  
数据类型是用来解决不同形式的数据在程序中的表达、存储和操作问题。Python支持的基本数据类型包括：数字、字符串、列表、元组、字典、集合。使用 type() 函数可以查看对象的数据类型。不同类型的对象可以存储不同形式的数据，支持不同的操作。

  
【注意】Python解释器会根据赋值结果自动推断变量类型（动态类型）。


  

    

      
类型示例说明常见运算

      
        
int 整数42, -10整数，无大小限制+ - * // % **

        
float 浮点数3.14, 1.5e10浮点数，有精度限制+ - * / **

        
str 字符串"hello", "你好"字符串，用引号包裹+ * in len()

        
bool 布尔True, False布尔值，只有两个and or not

        
list 列表[1, 2, 3]有序、可修改的序列索引、切片、len()

        
tuple 元组(1, 2)有序、不可修改的序列索引、切片、len()

# 猜数字游戏：整合本次课所有知识点
import random

# 变量 + 模块 + 运算符
secret = random.randint(1, 100)   # 随机生成1-100的秘密数字
count = 0                         # 计数变量

print("=== 猜数字游戏 ===")
print("我想了一个1到100之间的数字，你来猜！")

# 游戏循环（下节课学while，这里先体验）
while True:
    # input + 类型转换
    guess = int(input("请输入你的猜测："))
    count += 1                    # 复合赋值运算符

    # 关系运算符 + 逻辑运算符
    if guess == secret:
        print(f"恭喜你猜对了！答案就是{secret}")
        print(f"你一共猜了{count}次")
        break                     # 跳出循环
    elif guess < secret:
        print("太小了，再大一点！")
    else:
        print("太大了，再小一点！")

if bmi < 18.5:
    category = "偏瘦"
    advice = "建议增加营养摄入，适当增肌"
elif 18.5 <= bmi < 24:
    category = "正常"
    advice = "恭喜！请保持健康的生活方式"
elif 24 <= bmi < 28:
    category = "偏胖"
    advice = "建议控制饮食，增加有氧运动"
else:
    category = "肥胖"
    advice = "建议咨询医生，制定科学减重计划"
