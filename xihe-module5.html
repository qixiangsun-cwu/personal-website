✅ AI能在日常办公中帮我们做什么？

📝 起草初稿：你提供要点，AI写完整版本
🔄 修改润色：把口语化的文字改成正式公文
📋 结构化整理：把零散想法整理成有条理的文章
📊 格式规范：帮你调整公文格式（标题层级、落款等）
🌐 翻译：民族地区的双语材料（汉+藏/维）
♻️ 精简/扩写：把长文章缩短，或把短内容扩充

📝 办公①：写材料（讲话稿/汇报/总结）

💻 用什么软件写材料？

✅ 推荐1：豆包App/网页版
最直接：打开豆包，把要点发给它，让它写。支持长文档（可上传Word文件）。
✅ 推荐2：DeepSeek
需要深度思考的材料（如调研报告）用DeepSeek的"深度思考"模式，逻辑更严谨。
✅ 推荐3：WPS AI
WPS自带AI功能（会员），可以直接在Word里"生成草稿"，不用切换软件。
✅ 推荐4：WorkBuddy
需要生成格式规范的Word文档时用，直接生成.docx文件，不用复制粘贴。

💻 用什么软件做PPT？

✅ 推荐1：WorkBuddy（生成PPT文件）
直接告诉AI"帮我生成一份关于XX的PPT，共10页"，AI会生成.pptx文件，下载就能用。最省事！

🪪 办公③：证件照AI生成（不用去照相馆）

💡 场景：需要用证件照但没时间去照相馆

例如：要更新妇联干部信息表，需要近期免冠照片；或者要帮一位大姐申请低保，需要证件照。
传统做法：去照相馆拍，要花时间+花钱。AI做法：用手机自拍一张，AI帮你生成标准证件照！

💻 用什么AI工具生成证件照？

🤖 方法1：豆包（图片生成）
打开豆包 → 点击"图片生成" → 上传自拍照片 → 输入提示词（见右侧）→ 生成标准证件照
🎨 方法2：即梦AI
打开即梦AI → 选择"证件照生成"模板 → 上传照片 → AI自动生成符合规格的证件照

请帮我把这张照片生成一张标准免冠证件照： 【规格】1寸（2.5cm × 3.5cm），分辨率300DPI 【背景】纯白色（RGB 255,255,255） 【要求】 1. 保持原人物的脸部特征（不要变样） 2. 穿着正式（自动换成白色有领衬衫） 3. 发型整齐（如果头发乱，自动整理） 4. 光线均匀（脸部无阴影） 5. 输出为JPG格式，文件大小不超过200KB 【用途】用于妇联干部信息登记表

📝 办公④：会议纪要整理（录音→文字→结构化）

📱 完整流程：开会录音 → 转文字 → AI整理成纪要

  1. 第一步：录音 → 用手机录音App录会议内容（提前告知参会人"为了方便记录，我录个音"）
  2. 第二步：转文字 → 用"讯飞听见"App（免费）或豆包App的"语音转文字"功能
  3. 第三步：整理 → 把转写文字发给AI，让它整理成规范会议纪要（提示词见右侧）
  4. 第四步：核实 → AI整理后，自己核对一遍（特别是人名、数字、决议事项）

🤖 提示词：整理会议纪要

【角色】你是一位专业的会议纪要整理员，熟悉基层政府工作会议的常见内容和格式。 【任务】请把下面的会议录音转写文字整理成规范的会议纪要。 【要求】 1. 格式：标题、会议时间、地点、参会人员、主持人、记录人、会议议题、讨论内容（分点）、决议事项、下一步行动 2. 语言：正式、简洁、客观（不要带主观评价） 3. 把口语化表达改成书面语（比如"大家觉得行"改成"与会人员一致同意"） 4. 如果有不清楚的地方，在"备注"栏说明 5. 输出为可以直接复制到Word的格式

💡 实用技巧

  • ✅ 开会时坐在录音效果好的位置（离 speaker 近一点）
  • ✅ 如果会议很长，可以分段录音（每段不超过1小时）
  • ✅ 整理完纪要后，发给参会人确认（避免遗漏重要决议）
  • ✅ 把整理好的纪要存档，下次开会前先回顾上次决议

🎨 宣传①：用即梦AI生成海报（详细步骤）

🛠️ 即梦AI操作步骤（电脑版）

  1. 打开浏览器，访问 jimeng.jianying.com
  2. 登录：用抖音App扫码，或手机号验证码登录
  3. 首页点击 "AI绘画" → 选择尺寸"海报/封面"
  4. 在输入框写描述（提示词）→ 参考右侧模板
  5. 选择比例：手机转发用9:16，打印用3:4或A4
  6. 点击"生成" → 等待30秒 → 从4张结果中选最满意的
  7. 点击满意图片 → "下载"（免费每天约20次）

🛠️ Canva可画操作步骤（模板多）

  1. 打开 canva.cn → 微信/手机号注册登录
  2. 搜索栏输入"海报" → 出现几千个模板
  3. 筛选：尺寸选"A4"或"手机海报"，风格选"中国风"
  4. 点击模板进入编辑界面 → 双击文字修改内容
  5. 替换图片：点击图片 → "上传" → 选自己的照片
  6. 调整颜色：点击"背景" → 换颜色或换背景图
  7. 完成后点右上角"分享" → "下载为PNG"（免费）
💡 选型建议：赶时间/无设计基础 → 即梦AI（5分钟出图）；需要精确调整文字/排版 → Canva（30分钟，但完全可控）

🎬 视频①：用剪映制作宣传视频（详细操作步骤）

📱 剪映电脑版操作步骤（从新建到导出）

  1. 新建项目：打开剪映 → 点击"开始创作" → 输入项目名称（如"西和半夏宣传"）
  2. 导入素材：点击"导入"按钮 → 选择提前拍好的视频/照片 → 拖入下方时间线
  3. 剪辑排序：拖动片段调整顺序 → 点击片段两端可以裁剪长度 → 删除不要的部分
  4. 加字幕：点击顶部"文本" → "新建文本" → 输入文字 → 设置字体/颜色/动画
  5. 加背景音乐：点击"音频" → "音乐" → 搜索"乡村振兴"或"宣传片配乐" → 选择合适的一首
  6. 加转场：点击两个片段之间的小白方块 → 选择转场效果（推荐"叠化"或"黑场"）
  7. 加片头片尾：点击"模板" → 搜索"宣传片头" → 选一个 → 替换文字为你的内容
  8. 导出：点击右上角"导出" → 分辨率选1080P → 帧率30fps → 点击"导出"（约5-10分钟）
📱 手机版剪映
操作类似，但屏幕小。适合外出时快速剪辑，不适合做复杂效果。
💻 电脑版剪映
推荐！屏幕大，时间线看得清楚，适合做3分钟以上的视频。
⏱️ 时间估算
1分钟视频 ≈ 30分钟剪辑时间（含找素材、写文案、配音）。
