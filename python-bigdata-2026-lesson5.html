1.1 为什么需要函数

函数是实现特定功能的代码段。Python 里能用的函数有三类：内置函数（print、len、sum 这些，拿了就用）、标准库函数（要先 import，比如 math.sqrt）、以及我们自己写的函数。本章讲的就是第三类。

1.3 返回值：return 的三种情况

函数把结果交给调用者，靠的是 return。这里有三个必须分清的情况——尤其是第三种，它是初学者最容易踩的坑。

写法返回什么调用处拿到
return s一个值那个值本身（可以是任意类型）
return a, b多个值一个元组 (a, b)，可以用解包接收
没有 return（或只写 return）NoneNone——想去运算就会报错
三种返回值一次看全（含 return 会立刻结束函数） 
def f1(a, b):
    print('f1 只打印不返回：', a + b)      # 没有 return

def f2(a, b):
    return a + b                       # 返回一个值

def f3(a, b):
    return a + b, a * b, a - b         # 返回多个值 → 元组

def f4(n):
    if n > 0:
        return '正数'
    return '非正数'
    print('这行永远不会执行')            # return 之后函数就结束了

print('f1(3, 5) →', f1(3, 5))
print('f2(3, 5) →', f2(3, 5))
r = f3(6, 4)
print('f3(6, 4) →', r, type(r))
x, y, z = f3(6, 4)                     # 元组解包接收多个返回值
print('解包后：x =', x, ' y =', y, ' z =', z)
print('f4(10) →', f4(10), ' f4(0) →', f4(0))

函数的嵌套调用：一个函数的返回值喂给另一个函数 
def calc_avg(alist):
    return round(sum(alist) / len(alist), 1)

def judge_level(avg):
    if avg >= 90:
        return '优秀'
    elif avg >= 80:
        return '良好'
    elif avg >= 60:
        return '及格'
    else:
        return '不及格'

for name, scores in [('一班', [88, 92, 79, 95, 84]),
                     ('二班', [70, 65, 72, 68]),
                     ('三班', [55, 60, 48, 52])]:
    avg = calc_avg(scores)                    # 第一个函数算平均分
    print(name, '平均分', avg, '等级', judge_level(avg))   # 结果喂给第二个函数
运行结果（实测）
一班 平均分 87.6 等级 良好
二班 平均分 68.8 等级 及格
三班 平均分 53.8 等级 不及格

位置参数 · 默认值参数 · 关键字参数 · 可变长参数（*args / **kwargs）

参数是函数与外界交换数据的接口。同样一个函数，用不同的传参方式调用，写法不同、报错也不同。课件里把参数分成四类，这一节一类一类过，并且每一类都配了"写错的后果"——看懂报错信息，比背语法有用得多。

2.1 位置参数：数量相同、顺序一致

位置参数是最常见的形式。调用时实参和形参的数量必须相同、位置顺序必须一致——第一个实参给第一个形参，第二个给第二个，以此类推。

变量作用域

局部变量 · 全局变量 · 同名遮蔽 · global 关键字

作用域就是变量"起作用的代码范围"。函数给变量划了边界：函数内部定义的变量出了函数就消失。理解这一点，才能解释为什么有的变量"明明赋过值却说不存在"。

图 5-10　全局变量与局部变量：局部变量随函数"生",随函数"灭"

3.1 局部变量与全局变量

局部变量：在函数内部定义的变量，作用范围只限这个函数，函数执行结束后自动删除。全局变量：在函数外部定义，作用范围是整个程序，函数里也可以读。

函数里能用全局变量，函数外拿不到局部变量（课件示例） 
global_num = 5                       # 全局变量

def my_add2():
    local_num = 3                    # 局部变量
    return global_num + local_num    # 局部里读不到 global_num？→ 会去全局区找

print('函数内用全局变量：', my_add2())
print('函数外读全局变量：', global_num)
运行结果（实测）
函数内用全局变量： 8
函数外读全局变量： 5
写错会怎样：在函数外面访问局部变量 
def my_add2():
    local_num = 3
    return local_num

print(my_add2())        # 函数里面用，没问题
print(local_num)        # 函数外面用 → 局部变量已经消失了
运行结果（实测）
3
Traceback (most recent call last):
  File "<pyshell>", line 6, in <module>
    print(local_num)        # 函数外面用 → 局部变量已经消失了
NameError: name 'local_num' is not defined
✅ 本节小结：函数里可以读全局变量（找不到就"向上找"），但函数内部定义的变量是局部的——函数一执行完就销毁，外面访问会报 NameError: name 'xxx' is not defined。

3.2 同名时，局部优先

如果函数内部和外部定义了同名变量，函数体里用的是局部那个，外部的被"遮住"（shadow），而且函数内的修改不会影响外部那个。

同名变量：里外各一份，互不影响（课件示例） 
x = 5                     # 全局变量

def my_add3():
    x = 3                 # 局部变量，和全局的 x 同名
    return x + x          # 用的是局部那个 3

print('函数内的结果：', my_add3())      # 3 + 3 = 6
print('函数外的 x：', x)                 # 全局那个没被改动，还是 5

def my_add3b():
    return x + x          # 函数内没有定义 x → 去全局区找到 5

print('函数内没有同名变量时：', my_add3b())   # 5 + 5 = 10

函数外的 x： 5

✅ 本节小结：Python 找变量的顺序是先局部、再全局。同名时"近的赢"——函数里用的是局部变量，全局那个毫发无损。变量重名看着方便，实际是 bug 的温床，起名时尽量避开。

3.3 global：在函数里修改全局变量

如果确实要在函数内部修改全局变量，必须先用 global 声明它。不声明就赋值，Python 会把它当成一个新的局部变量——这时如果函数里还想先读后写，就会撞上那个著名的 UnboundLocalError。

    print('函数内读到 x =', x)      # 读到 5
    x = 3                   # 修改全局变量
    return x + x

print('返回值：', my_add4())
print('函数执行后，函数外的 x =', x)     # 被改成了 3

    # 没有 global，这里只是在函数内新建了一个局部变量

5.1 递归的两个要素

递归函数就是在函数体里调用自己。但它必须写清楚两件事，缺一个就会无限调用下去：

  1. 终止条件（base case）：什么时候停下来，直接返回一个确定的值，不再调用自己；
  2. 递归式：把问题变小一步，再交给自己处理——每一次调用都要比上一次更接近终止条件。

递归①：阶乘 n! = n × (n-1)!，0! = 1 是终止条件 
def factorial(n):
    '''计算 n 的阶乘：终止条件写在最前面'''
    if n <= 1:                 # 终止条件：不再调用自己
        return 1
    return n * factorial(n - 1)   # 递归式：规模缩小 1

for n in range(1, 7):
    print(n, '的阶乘 =', factorial(n))

print('组合数 C(5,2) = 5! / (2! × 3!) =', factorial(5) // (factorial(2) * factorial(3)))

def sum_rec(nums):

    total = 0
    for n in nums:
        total += n
    return total

5.2 递归还是循环？

同一个"求和"，循环和递归都能做。工程上的默认选择是循环——它更省内存、没有深度限制；递归的优势在"问题本身就是分层的"：文件夹里的文件夹、菜单里的子菜单、族谱里的分支，用递归写出来几乎就是问题本身的样子。

比较项循环（for / while）递归
写法复杂度直白，一眼看到"从头到尾"代码更短，但要想清终止条件
内存占用几乎不额外占内存每一层调用都压一个栈帧，深度越大越占内存
深度限制没有限制Python 默认约 1000 层，超了报 RecursionError
适合什么一维、顺序处理的数据天然分层的结构：树、目录、嵌套列表
本章建议首选看懂即可，别用来处理大批数据

6.1 类与对象：模板与实例

到这里为止，函数和数据是分开的：列表存数据，函数处理数据。类（class）把两者装在一起——它描述"这类东西有什么数据（属性）、能做什么（方法）"。类是抽象的模板，对象是按模板造出来的具体实例。

属性对象的数据（静态特征）self.r 半径
方法对象的函数（动态行为），第一个参数必须是 selfarea()、perimeter()
✅ 本节小结：类是模板，对象是实例。类里规定两件事：属性（有什么数据）和方法（能做什么）。造对象的过程叫"实例化"——同一个类可以造出很多对象，它们的属性值互不相同。

分段函数：封装成函数，主程序只负责遍历输入 
def piecewise(x):
    '''分段函数：
       x < 0        → y = x²
       0 ≤ x < 5    → y = 3x - 5
       x ≥ 5        → y = 0.5x - 2
    '''
    if x < 0:
        y = x ** 2
    elif x < 5:              # 走到这里已经隐含 x >= 0
        y = 3 * x - 5
    else:
        y = 0.5 * x - 2
    return y

for x in [-3, -0.5, 0, 2, 4.9, 5, 10]:
    print('x =', x, '→ y =', piecewise(x))

    '''两边之和大于第三边'''
    return a + b > c and a + c > b and b + c > a

    '''海伦公式：p 是半周长'''
    p = (a + b + c) / 2
    return math.sqrt(p * (p - a) * (p - b) * (p - c))

def is_prime(n):
    '''判断 n 是否为素数'''
    if n < 2:                      # 1 和负数都不是素数
        return False
    for i in range(2, int(n ** 0.5) + 1):

def word_rank(text, top=3):
    '''返回出现次数最多的前 top 个词：[(词, 次数), ...]'''
    counts = {}
    for w in text.split():
        counts[w] = counts.get(w, 0) + 1
    rank = sorted(counts.items(), key=lambda kv: kv[1], reverse=True)
    return rank[:top]

import math

def sigmoid(z):
    '''激活函数：把任意数压到 0~1 之间'''
    return 1 / (1 + math.exp(-z))

def neuron(inputs, weights, bias):
    '''一个神经元：先加权求和，再过激活函数'''
    z = bias + sum(x * w for x, w in zip(inputs, weights))
    return round(z, 3), round(sigmoid(z), 3)

def mse(preds, truths):
    '''均方误差：预测值与真实值差多少（越小越好）'''
    n = len(preds)
    total = sum((p - t) ** 2 for p, t in zip(preds, truths))
    return round(total / n, 4)

AI 渗透③：用类封装一个"迷你模型"，并让它自己变准 
class TinyModel:
    '''把"参数 + 前向计算 + 损失 + 训练"装进一个类：这就是模型对象'''

    def __init__(self, w=0.5, b=0.0):
        self.w = w
        self.b = b

    def forward(self, x):
        '''前向计算：y = wx + b'''
        return self.w * x + self.b

    def loss(self, xs, ys):
        '''均方误差'''
        return round(sum((self.forward(x) - y) ** 2 for x, y in zip(xs, ys)) / len(xs), 4)

    def fit(self, xs, ys, lr=0.02):
        '''一步梯度下降：往"让损失变小"的方向挪一点点'''
        n = len(xs)
        gw = sum(2 * (self.forward(x) - y) * x for x, y in zip(xs, ys)) / n
        gb = sum(2 * (self.forward(x) - y) for x, y in zip(xs, ys)) / n
        self.w -= lr * gw
        self.b -= lr * gb

xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]            # 真实规律是 y = 2x + 1

m = TinyModel()
print('训练前：w =', round(m.w, 3), ' b =', round(m.b, 3), ' 损失 =', m.loss(xs, ys))

for _ in range(300):
    m.fit(xs, ys)

print('训练后：w =', round(m.w, 3), ' b =', round(m.b, 3), ' 损失 =', m.loss(xs, ys))
print('拿它预测没见过的 x = 6 →', round(m.forward(6), 2), '（真实答案 13）')
print('（这就是机器学习最小可运行的骨架：定义模型、算损失、调参数）')

一、知识点总结卡

函数基础

  • 定义：def 函数名(形参): + 缩进的函数体
  • 调用：函数名(实参)，实参按位置交给形参
  • 函数必须先定义、后调用
  • 没有 return → 返回 None
  • 返回多个值 → 元组，可用解包接收
  • 形参不写类型，由实参决定

函数参数

  • 位置参数：数量相同、顺序一致
  • 默认值参数：def f(x, y=10)，必须写在最后
  • 关键字参数：f(y=5, x=4)，顺序可换
  • 混用时：位置在前、关键字在后
  • *args 打包成元组，**kwargs 打包成字典
  • 默认值别用可变对象（写 None 再新建）

变量作用域

  • 局部变量：函数内定义，函数结束即销毁
  • 全局变量：函数外定义，函数内可读
  • 同名时局部优先（遮蔽）
  • 要在函数内改全局变量 → global 变量名
  • 查找顺序：先局部，再全局

lambda · 递归

  • lambda 参数: 表达式，没有名字、只有一行
  • 不能赋值、不能写语句
  • 最常用：sorted(数据, key=lambda x: 依据)
  • 递归 = 终止条件 + 自己调用自己（规模要变小）
  • 递归有深度限制，能用循环就用循环

类与对象

  • 类 = 模板，对象 = 实例
  • class 类名:，类名首字母大写
  • __init__(self, …) 创建对象时自动执行，用来存属性
  • 方法的第一个参数必须是 self
  • 访问：对象.属性、对象.方法()
  • 同一个类造出的对象互相独立

一句话主线

  • 主程序应该只看见"做什么"，看不见"怎么做"
  • 能用名字复用的逻辑 → 写成函数
  • 数据和处理数据的方法总是一起出现 → 写成类
  • 参数是接口，返回值是结果，作用域是边界
  • AI 里的前向计算、权重、超参数、模型对象，都从这里长出来
