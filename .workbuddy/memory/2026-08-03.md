# 2026-08-03 工作记录

## 个人网站优化分析（index.html / workspace.html / styles.css / script.js）

审查了孙琪翔个人网站（公开页 + 私有工作台 + 玻璃拟态样式体系），关键发现：

1. **安全硬伤**：`workspace.html` 密码 `Sqx15973@` 明文硬编码在 JS 中，源码即泄露；"在研项目进度/援外资料库/平台询价"等敏感信息等同公开，`noindex` 无效。
2. **移动端导航缺失**：`<768px` 时 `.nav-links{display:none}` 且无汉堡菜单，公开页所有板块在手机上不可达。
3. **workspace 是静态公告板**：项目进度/待办/资料全部写死 HTML，无增删改、无 localStorage 持久化、无"今天要处理"置顶、无数据备份导出，非真正工作台。
4. **新闻 fetch 本地 JSON**：`file://` 双击打开时 CORS 拦截，`ai-news.json` 加载失败，永远显示"加载中"。
5. **流量统计语义混乱**：读公开页 localStorage，且 localhost 仅本机，统计无实际意义。
6. **外部字体依赖**：Google Fonts 的 Noto Serif SC 国内网络下慢/不稳；body 用衬线体偏"论文风"。
7. **多处"待补充"占位符**（视频 BV 号、B站链接、提示词模板、3/4 下载项）降低专业感。
8. **emoji 当图标**：全站 emoji 图标，但 `redesign/` 目录已有 40+ 内联 SVG 图标未启用；emoji 跨平台渲染不一致。
9. **双版本并存**：根目录主站 vs `孙琪翔个人网站-苹果风-redesign/` 另一套，易部署混淆。

建议优先级：移动端导航 > workspace 安全与可交互化 > 去外链/新闻兜底 > 内容补全与视觉统一。
