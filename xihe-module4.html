🧮 Excel台账③：公式与函数实操

📊 COUNTIF：统计各类问题数量

=COUNTIF(H:H,"家暴") → 统计H列（问题类型）中"家暴"出现的次数 =COUNTIFS(H:H,"家暴",N:N,"是") → 统计"家暴"且"已办结"的数量
💡 用途：年度汇报"今年处理了XX起家暴案件"

📅 DATEDIF：计算处理时长

=DATEDIF(B2,O2,"D") → 计算B列（来访日期）到O列（办结日期）的天数差 =IF(O2="","未办结",DATEDIF(B2,O2,"D")) → 如果还没办结，显示"未办结"
💡 用途：统计"平均处理天数"，改进工作效率

🔍 VLOOKUP：查找重复来访

=IF(COUNTIF(C:C,C2)>1,"重复来访","首次") → 在C列（姓名）中查找是否出现超过1次 =VLOOKUP(C2,台账!C:O,13,FALSE) → 从另一个工作表"台账"中查找该人的处理结果
💡 用途：发现"反复求助"的人员，可能需要深度介入

🔧 Excel台账⑥：常见问题与解决

❌ 问题1：#N/A错误（VLOOKUP找不到）

💡 原因：查找值不在查找区域中（可能姓名有空格/错别字）
✅ 解决：用TRIM()函数去除空格，或改用COUNTIF先检查是否存在
=TRIM(C2) → 清除C2单元格的首尾空格

❌ 问题2：日期格式混乱

💡 原因：有人写"6月24"，有人写"2026.6.24"，Excel不认
✅ 解决：全选日期列 → 右键"设置单元格格式"→ 选"日期"→ 确定

❌ 问题3：数据透视表不更新

💡 原因：透视表的数据源范围是固定的，新增行没包含进去
✅ 解决：把数据源设为"表格"（Ctrl+T），透视表会自动扩展。或右键 → "刷新数据"

❌ 问题4：文件太大打不开

💡 原因：几年数据都在一个文件里，超过Excel行数限制或文件过大
✅ 解决：按年份分成不同文件，或用"腾讯文档"在线表格（不限行数）
💡 遇到解决不了的问题，把错误截图发给AI，它会告诉你怎么办！

📊 台账②：Excel数据验证和格式设置（详细步骤）

🛠️ 设置下拉菜单（活动类型列）

  1. 选中C列（活动类型）→ 点击菜单"数据" → "数据验证"
  2. 在"允许"下拉框选"序列"
  3. 在"来源"输入：健康讲座,技能培训,文娱活动,维权服务,心理辅导
  4. 点"确定" → C列每个单元格右下角会出现下拉箭头
  5. 同理设置J列（主要参会人群）和O列（跟进状态）

🛠️ 设置日期格式（活动日期列）

  1. 选中D列（活动日期）→ 右键 → "设置单元格格式"
  2. 在"分类"选"日期" → 在"类型"选"2023-03-14"格式
  3. 点"确定" → 输入日期时会自动格式化为"2025-03-15"
  4. 小技巧：输入日期快捷键：Ctrl+;（分号）→ 自动填入今天日期
  5. 同样设置E列（开始时间）为时间格式"13:30"

🛠️ 设置数字格式（经费列）

  1. 选中K列（活动经费）→ 右键 → "设置单元格格式"
  2. 选"分类"= "货币" → "小数位数"= 2
  3. 选"货币符号"= "¥" → 点"确定"
  4. 输入数字时会自动显示"¥1,200.00"格式

🛡️ 保护工作表（防止误删）

  1. 点击菜单"审阅" → "保护工作表"
  2. 设置密码（可选，记住密码！）→ 勾选"选定未锁定的单元格"
  3. 点"确定" → 此时表头行（第2行）不能被改
  4. 如需修改 → "审阅" → "撤销工作表保护" → 输入密码

📊 台账③：Excel公式设计——自动统计活动数据

📝 在台账旁边（如S列起）建"统计面板"

📊 统计今年活动总数

=COUNTIF(D:D,">=2025-01-01")

说明：D列日期≥2025年1月1日的行数

📊 统计"健康讲座"类活动数

=COUNTIF(C:C,"健康讲座")

说明：C列等于"健康讲座"的行数

📊 计算平均参与人数

=AVERAGE(I:I)

说明：I列实际参与人数的平均值

📊 统计待跟进问题数

=COUNTIF(O:O,"进行中")

说明：O列等于"进行中"的行数

💡 更多实用公式

总和：=SUM(K:K)
（总经费）
最大：=MAX(I:I)
（最高参与人数）
条件计数：=COUNTIFS(C:C,"健康讲座",O:O,"已完成")
（已完成的健康讲座数）
