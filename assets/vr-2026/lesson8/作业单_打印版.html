2.2 转换：把模型变成 一个 .glb（7′）

打开 学生课堂作业包\pages\03_模型转换器.html（双击即可，单文件、零外部请求）：

  1. 点「选择文件」或把下载到的文件拖进窗口（支持多选：x.gltf + x.bin + textures\*.jpg 一起拖）；
  2. 看统计：网格数 / 三角面 / 材质 / 纹理 / 动画 / 源大小；输入是 .glb 时还会多一栏「体积变化 sizeDeltaPct」（转换≠优化的证据）；
  3. 点「导出 GLB」，得到 <你的模型>.glb；
  4. 看页面「③ 输出 GLB 头校验」一栏：magic 应为 glTF、version 应为 2、声明长度应等于文件字节数——这是"转换真的成功"的最硬证据；
  5. 把 GLB 也放进自己的提交文件夹（见 §五）。

转换失败排查：.gltf 单独拖会缺 .bin/纹理 → 多文件一起拖（且保留相对路径）；.fbx 版本太老 → 换 Poly Haven 的模型重下；页面无反应 → 确认拖的是文件不是文件夹；.obj 通常不带贴图（本页不解析 .mtl）。

2.3 导入模型工作台，完成 3 个操作（8′）

  1. 点「选择 .glb 文件」选你刚转好的 .glb（或直接拖进页面）；
  2. 模型会按包围盒归一化到约 1.2 m 高、贴地、居中（代码里是 NORM_HEIGHT = 1.2）——记下"导入后它有多大"；

2.7 B 进阶 / C 挑战（练习 2，选做）

B（＋2，选 1）

  • B1 换色板 + 动画切换：在工作台里给你的模型换 2 个颜色、带动画的模型切一次动画，然后导出场景 JSON——证明这些状态真的进了文件（JSON 里 color / anim 变了）。
  • B2 场景 JSON 讲解：打开 JSON，用 3 行话说明每个字段是干什么的（pos / rot / scale / anim / triangles / license）。
  • B3 二次转换探索（机房就能做，不用命令行）：把同一个 .glb 再丢进 pages\03_模型转换器.html 再转一次（GLB→GLB），记下前后字节（例：Duck.glb 120,484 → 152,408 B，+26.5%），回答：为什么“转换”反而变大？（提示：贴图被重新编码）——这正是“转换 ≠ 优化”。

C（＋1，选 1）

  • C1 多文件一次转换：用 Poly Haven 的 x.gltf + x.bin + textures\*.jpg 一次转成单个 GLB（这就是真实工作流），并说明"为什么单独拖 .gltf 会失败"。
  • C2 许可判断：把 DamagedHelmet.glb 也转换一次，判断它能不能进你的期末作品，写出理由（引用许可名 + 原文要点）。
  • C3 改工作台参数（机房可直接做，不用重建）：用记事本打开 pages\02_模型工作台_WebXR.html，Ctrl+F 搜「学生练习区」，改 var NORM_HEIGHT = 1.2;（归一化高度）或 var PALETTE = [...]（色板），Ctrl+S 保存 → 浏览器 F5 刷新 即生效（模型重新加载后可见）。交：改前/改后截图 + 一行“改的是哪个常量、为什么”。

2.8 常见坑（练习 2）

现象 原因 怎么修
模型导进来巨大/极小源模型单位不是米用工作台的归一化（NORM_HEIGHT=1.2）或手动缩放；或在转换前统一单位
模型悬空/陷地原点不在脚底导入后手动下移，记录你移动的数值
模型全黑缺贴图 / 法线问题多文件一起拖；或换 GLB 直链重下
导出 GLB 失败缺 .bin 或纹理 → 相对路径断了按 2.2 的多文件拖法；C1 就是练这个
场景 JSON 是空的没选中模型就导出先在场景里选中/加入模型再导出
许可写着"不确定"站点没写清写"不确定"比编一个强，并注明"待核实"（如 WaltHead.obj / SambaDancing.fbx）
按 Khronos 新仓库链接下 CesiumMan，字节对不上新仓库已重导出（438,044 B），与本地/课堂用的 490,956 B 不同用旧仓库链接：glTF-Sample-Models/main/2.0/CesiumMan/glTF-Binary/CesiumMan.glb
Poly Haven 取资产返回 404资产 id 大小写敏感（ArmChair_01，不是 armchair_01）按站点上的 id 原样写；先 api.polyhaven.com/info/<slug> 验证
转换后反而更大（如 Duck 120,484 → 152,408 B，+26.5%）转换 ≠ 优化：贴图重编码、缓冲重排要更小得做减面 / 贴图降采样 / Draco / meshopt；这条正是 B3 的题目
把 .gltf 直接拖进工作台没反应工作台只收 .glb（accept=".glb"，拖非 .glb 只弹中文提示）先用 03 转换器转成 .glb；这正是"管线要串起来"的原因
.fbx 转不动 / 特别慢.fbx 可能是压缩数组，页面靠内联 fflate 解压；大文件（SambaDancing 3.68 MB → 9.9 MB GLB）很吃内存换小模型；或直接用 Poly Haven 的 .gltf 多文件
网络不通、下载失败教室网络/站点问题改用 学生课堂作业包\offline_models\，记录写"教师离线包"，照常给分
