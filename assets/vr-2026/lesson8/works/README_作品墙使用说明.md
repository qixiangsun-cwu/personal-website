# 第 8 次课 · 作品墙使用说明（教师）

> 原则：**全部提交都上墙，不筛选**。每件作品 = 一张 16:9 截图 + 一句话（≤30 字）+ 模型许可。
> 作品墙页面：`vr-2026-lesson8-works.html`（线上 `/vr-2026-lesson8-works`）。

## 一、收作业要求（已经写在一页版作业里）

每个学生交一个文件夹 `学号_姓名_第8次课/`，内含：

- `S2.png`：02 模型工作台操作后的截图（16:9、≥1280×720、含 HUD、无隐私）——**上墙用这一张**
- `scene.json`：02 导出
- `许可卡.txt`：模型名 / 来源 / 许可 / 能否商用 / 是否署名
- `说明.md`：第一行 ≤30 字（上墙文案）；如不愿公开真名，另起一行 `公开名：昵称`；如不愿上墙，第一行写 `不公开`

## 二、三步把全部作品放上去

1. **收齐**：把全班文件夹放到一个根目录（例如 `D:\收作业\第8次课_20261028`）。
2. **生成**：在站点 `assets\vr-2026\lesson8\works` 目录运行：

```powershell
py -3 build_works.py --src "D:\收作业\第8次课_20261028" --out "D:\各种工作\个人网站\assets\vr-2026\lesson8\works"
```

脚本会：
- 复制截图 → `works/<学号>.png`
- 读 `说明.md` 的一句话、`公开名：`、`不公开`
- 读 `许可卡.txt` 的模型与许可
- **重写 `works-data.js`**（全部作品，按学号排序）
- 生成 `works-manifest.csv`（核对用：谁上了、谁 skip、为什么）

3. **部署**：在站点仓库运行：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\各种工作\个人网站\assets\vr-2026\lesson8\works\deploy_works.ps1"
```

约 1 分钟后 Cloudflare Pages 生效（刷新 `/vr-2026-lesson8-works`）。

## 三、注意

- 作品墙上**按学号排序**，不按分数、不筛选；`不公开` 的不会被上传（但清单里保留记录）。
- 如学生 `说明.md` 缺一句话，脚本写“（未写说明）”并标在清单里，教师可让学生补。
- 图片统一复制为 `works/<学号>.png`；重复运行会覆盖同名文件，不会重复添加。
- 作品墙页支持搜索（学号/姓名/关键词）；数据在 `works-data.js`，也可手工编辑。
- 建议课堂节奏：第 3–4 节前 10 分钟收齐 → 脚本生成 → 部署 → 课堂里滚动展示全部作品。
