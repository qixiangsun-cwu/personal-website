故宫 · 紫禁城 WebXR 漫游 —— 作业改动说明
姓名：刘晓希    学号：230812034

本作业基于课堂案例「故宫 · 紫禁城 WebXR 沉浸漫游」改造，共 4 处改动：

1.【新增物体】姓名牌  buildNamePlaque()
  出生点右前方 (14, 0, 52) 立一座牌坊：两根立柱 + 金色柱头 + 石顶帽。
  牌面文字用 canvas 现场绘制（VR 技术课程作业 / 230812034 / 刘晓希），
  不依赖任何外部图片文件；牌面带自发光材质（emissiveIntensity 0.25）。

2.【新增物体】太和殿前鎏金铜狮一对  buildBronzeLions() / buildLionUnit()
  立于太和殿前广场中轴两侧 (±12, 0, 26)，坐狮造型：后躯蹲坐、挺胸、
  直立前腿带趾、三圈螺旋鬃毛、吻部/眉骨/眼珠/耳朵、额间宝珠、璎珞项圈、
  上扬卷尾；下承须弥座（圭角-下枋-束腰-上枋四层）。

3.【程序化贴图】tex.bronze / tex.bronzeBump
  铜狮使用 512×512 程序生成贴图：底金渐变 + 铜绿锈斑 + 鎏金流痕 + 錾刻卷草纹，
  另配同款灰度凹凸贴图模拟铸造颗粒感。全部 canvas 现画，零外部资源。

4.【改灯光】姓名牌面自发光：把 HUD「时辰」滑条拖到夜间（20:00 后）
  名字依旧清晰可读，普通匾额做不到。

★ 为什么名字做成 3D 牌子而不是网页文字：
  WebXR 沉浸模式下 HTML 覆盖层（div / HUD）不会被渲染，
  所以姓名必须放在 3D 场景物体上才会在头显里显示出来。

— 运行环境说明 —
· index.html + three.min.js 为必需文件；
  manifest.webmanifest / sw.js / icon.svg / icon-192.png 为「安装为应用（PWA）」功能所需。
· three.min.js 为 Three.js r128，请勿替换为其他版本（案例使用了 r128 的 API，换新版会报错白屏）。
· 必须通过 http / https 访问（本地可 python -m http.server 8080），不要双击用 file:// 打开——
  非安全上下文下浏览器不提供 WebXR，「进入 VR」按钮不会出现。
· 全部贴图与几何均为程序化生成，无外部模型/图片依赖，离线可用。
