 02
定位方式对比
Outside-In / Inside-Out / SLAM
切换三种定位方案 × 六种环境场景（弱光、白墙、遮挡、快速运动…），实时显示追踪状态。
 03
6DoF 自由度演示
3 旋转 + 3 平移
3DoF 下平移被锁死——你只能转头，走不近目标。切到 6DoF 体会运动视差与"走近看细节"。
 04
手部追踪与交互方式
手柄 / 手势 / 眼动 / 语音 / 动捕
五类输入的原理、延迟、优劣对比；含 22 关节点手骨图与六种手势失效场景模拟。
 05
MR 透视与空间网格
彩色透视 / iToF / 语义分割
叠加开关：透视画质、空间网格、AI 语义标签、虚实遮挡、深度图；拖 PPD 滑块看画质劣化。
 06
WebXR 能力检测
浏览器即平台
检测当前设备的 WebXR 会话与特性支持。机房 PC 与 PICO 浏览器结果对比，是 A7/B4 任务。

建模 / 引擎 / 资产 / 验证 · 五道关
