## 五、注意事项

1. 页面示例使用固定随机种子（0 / 10 / 25），下载的代码每次运行结果都与页面一致，可以对照检查。
2. `np.sort(x)` 返回**排好序的新数组**，原数组不变；`x.sort()` 是**原地排序**，会改掉 `x`。两者结果看起来一样，但对原数组的影响完全不同。
3. 页面里标注“故意报错”的示例（下标越界、广播失败、reshape 元素数不匹配等）没有收进 .py 文件（这些代码运行会中断），需要看效果请到页面上点「运行」。
4. CSV 文件是 **UTF-8 编码**，Excel 打开中文正常；用 pandas 读取不用额外指定编码。
5. 运行报 `ModuleNotFoundError: No module named 'numpy'` 时，先执行 `pip install numpy`。
6. 页面上的代码可以直接点「复制代码」拷到自己的编辑器里运行；示例代码里的每一段都是独立的，可以只挑需要的段落复制。
