## 二、怎么运行（复习与练习）

1. 把 `订单.xlsx`、`订单_new.xlsx`、`练习1_参考答案.py` 放同一个文件夹；
   `订单_lx2.xlsx`、`练习2_参考答案.py` 放同一个文件夹（也可以混放，脚本按文件名找）。
2. 命令行里执行：

   ```bat
   python 练习1_参考答案.py
   python 练习2_参考答案.py
   ```

3. 脚本会在同目录生成图片（`第5周各商品总金额.png`、`卫衣各周总金额.png`、`围巾每日订购数量.png`）
   和 `订单结果.xlsx`。

## 三、怎么运行（第 9 章可视化）

1. 把 `产量.csv`、`订单_new.xlsx`、`第9章_可视化示例代码.py` 放在同一个文件夹。
2. 执行 `python 第9章_可视化示例代码.py`，脚本会逐段绘图并保存 PNG（默认存当前目录）。
3. 每段开头都写了对应的例号（例 9-1、例 9-2……），可以和页面上的图、代码逐段对照。
4. 中文字体：脚本已设 `plt.rcParams['font.sans-serif'] = ['SimHei']`；macOS 可改成
   `['Arial Unicode MS']`，Linux 装一个中文字体后改对应名称即可。

## 五、环境与两个注意点

- 依赖：`pip install pandas openpyxl matplotlib`（pandas 2.2+ 均可；本机为 pandas 3.0.5 + matplotlib 3.11.2）。
- pandas 3 中 `pd.cut` 默认左开右闭；`pivot_table` 的 `margins=True` 会多出 `All` 行/列，
  画图前记得 `drop('All')`。
- 读 Excel 需要 openpyxl；读 GBK 编码的 CSV 要写 `encoding='gbk'`。
