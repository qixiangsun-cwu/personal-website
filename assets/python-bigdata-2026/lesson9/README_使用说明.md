## 二、怎么运行

1. 把 `订单.xlsx`、`订单_new.xlsx`、`练习1_参考答案.py` 放同一个文件夹；
   `订单_lx2.xlsx`、`练习2_参考答案.py` 放同一个文件夹（也可以混放，脚本按文件名找）。
2. 命令行里执行：

   ```bat
   python 练习1_参考答案.py
   python 练习2_参考答案.py
   ```

3. 脚本会在同目录生成图片（`第5周各商品总金额.png`、`卫衣各周总金额.png`、`围巾每日订购数量.png`）
   和 `订单结果.xlsx`。

## 三、和课程页面的关系

- 页面里「练习一 / 练习二」的题目顺序、代码提示、参考答案数字都与本资料包一致。
- 页面统一用 12 行精简数据演示同样的 API；完整数据请用本包里的文件。
- 页面上的「运行」按钮展示的是本机实测结果（Python 3.14.7 + pandas 3.0.5），
  不是浏览器里真的执行 Python；要现场跑请用 Jupyter 或命令行。

## 四、环境与两个注意点

- 依赖：`pip install pandas openpyxl matplotlib`（pandas 2.2+ 均可；本机为 pandas 3.0.5）。
- pandas 3 中 `pd.cut` 默认左开右闭；`pivot_table` 的 `margins=True` 会多出 `All` 行/列，
  画图前记得 `drop('All')`。
- 读 Excel 需要 openpyxl；读 GBK 编码的 CSV 要写 `encoding='gbk'`。
