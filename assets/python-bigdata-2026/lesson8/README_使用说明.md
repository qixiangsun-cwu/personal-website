配套页面：https://www.qixiangsun.com.cn/python-bigdata-2026-lesson8

## 一、运行环境

- Python 3.10+（本课页面实测环境：Python 3.14.7 + pandas 3.0.5）
- 需要安装：`pip install pandas openpyxl numpy`
- 在命令行进入本资料所在文件夹，执行 `python 文件名.py`

## 二、数据文件

- `订单.xlsx`（90.0 KB）：原始订单数据（310 行 × 7 列），含缺失值、异常值（含金额为 0 的订单；数量为 0 的情形用 12 行精简数据演示）；完整数据里没有完全重复的行，重复值问题用 12 行精简数据演示。课件例 8-4—8-11 都用它。

- `订单_clean.xlsx`（16.5 KB）：删除缺失值后的订单数据（305 行 × 7 列），例 8-8 的结果。
- `订单_fill.xlsx`（16.7 KB）：填充缺失值后的订单数据（310 行 × 7 列），fillna 练习结果。
- `订单_J1.xlsx`（15.3 KB）：1 月上半月订单（160 行），concat 合并练习（例 8-39）。
- `订单_J2.xlsx`（18.0 KB）：1 月下半月订单（172 行），concat 合并练习（例 8-39）。
- `订单_Jan.xlsx`（17.6 KB）：合并后的 1 月订单（332 行），例 8-39 的结果。
- `商品.csv`（194 B）：商品信息表（7 种商品：进价 / 产地 / 库存 / 销售价），merge 连接练习（例 8-40）。注意：GBK 编码，读取要写 encoding='gbk'。
- `订单_part.csv`（6.6 KB）：订单日期 / 商品名称 / 数量 三列（例 8-6 的导出结果）。注意：GBK 编码。
- `精简订单数据.csv`（624 B）：页面示例统一使用的 12 行精简订单数据（UTF-8），含缺失值 / 重复值 / 异常值三类问题，便于跟着页面敲代码。
- `学生成绩.csv`（68 B）：第 1—3 章示例用的学生成绩小表（4 门课 × 2 名同学），UTF-8。
- `月度销售_2025.csv`（283 B）：课后作业 1 使用的 2025 年 12 个月销售数据（随机种子 42，与参考答案一致），UTF-8。

## 五、注意事项

1. 页面示例统一使用 12 行「精简订单数据」，课件完整数据是 310 行的 `订单.xlsx`；作业与综合练习请用完整数据。
2. `商品.csv` 与 `订单_part.csv` 是 **GBK 编码**（与课件一致），读取要写 `encoding="gbk"`；其余 CSV 是 UTF-8。
3. pandas 3.0 与旧版有差异：`freq="M"` 已改为 `"ME"`；字符串列 dtype 显示为 `str`（旧版 `object`）；`df.info()` 输出格式也变了。页面与代码均以 pandas 3.0.5 实测为准。
4. 运行示例代码时如果提示找不到 `订单.xlsx` 等文件，请确认数据文件与本文件在同一文件夹。
5. 页面上的代码可以直接点「复制代码」拷到自己的编辑器里运行。
