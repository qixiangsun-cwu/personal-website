1.1　顺序结构：程序的默认形态

程序从上往下、一行一行、不跳过、不回头地执行——这就是顺序结构，它是所有程序的默认形态。分支和循环都是在这个"默认流水"上打岔：先认清默认，才知道岔在哪儿。

例 2-8（复习）计算圆的面积 
# 顺序结构：三条语句依次执行
r = 5
pi = 3.14159
area = pi * r * r
print("圆的面积：", area)
运行结果（实测）
圆的面积： 78.53975
✅ 本节小结：顺序结构 = 从上到下一行行执行。它是"默认流水"，分支和循环都是在这条流水上"打岔"，所以判断一段代码有没有写歪，先看它是不是默认从上到下。

1.3　单分支选择结构：满足才做

语法：if 条件表达式: 换行缩进写语句块。三条铁律（教材原文）：① Python 靠缩进表达代码层次，不是靠大括号；② 行尾冒号表示缩进开始，缩进结束表示代码块结束；③ 同一级别的语句块，缩进量必须相同。

单分支：输入 8（偶数时会多打印一行） 
x = int(input("输入一个数字："))
if x % 2 == 0:
    print("偶数")
print("判断结束")        # 这一行已经退出 if 了，无论如何都执行
运行结果（实测 · 输入 8）
输入一个数字：8
偶数
判断结束
同一段代码：输入 7（奇数时不打印"偶数"） 
x = int(input("输入一个数字："))
if x % 2 == 0:
    print("偶数")
print("判断结束")
运行结果（实测 · 输入 7）
输入一个数字：7
判断结束
缩进写错，两种下场：一种是直接报 IndentationError（好办，报错就改）；另一种是不报错、但逻辑悄悄错了（难查）。把 print("判断结束") 缩进到 if 里面，它就变成"只有偶数才打印"——程序照跑，答案错了。
✅ 本节小结：冒号起缩进，去缩进结束代码块，同级必须对齐。 单分支只处理"满足时做什么"，不满足就什么都不做、直接往下走。

1.4　双分支选择结构 进度表点名

两个分支互斥且穷尽：条件成立走语句块 1，否则走语句块 2，二选一，没有第三种可能。

例 3-1：判断奇偶数（输入 7） 
x = int(input())
if x % 2 == 0:
    print("偶数")
else:
    print("奇数")
运行结果（实测 · 输入 7）
7
奇数
最常见的错法：给 else 加条件。 else x % 2 == 1: 会直接 SyntaxError。记住：else 的含义是"以上都不成立"，所以它后面永远不写条件。
✅ 本节小结：二选一用 if-else；else 后面不写条件，写了就是语法错误。两个分支互斥且穷尽，程序一定会走其中一条。

1.5　多分支选择结构 进度表点名

语法为 if / elif / elif / … / else，其中 else 部分可选。教材原话："如果所有表达式都为 False，且存在 else 部分，则执行语句块 n。"

例 3-2：成绩等级判断（输入 85） 
score = int(input("请输入成绩："))
if score > 100 or score < 0:
    result = "输入错误，成绩必须在 0 到 100 之间"
elif 80 <= score <= 100:
    result = "A"
elif 60 <= score < 80:
    result = "B"
else:
    result = "C"
print("成绩等级：", result)
运行结果（实测 · 输入 85）
请输入成绩：85
成绩等级： A
边界值全测：把 8 个关键值一次性验完 
# 合法性检查必须放在第一个：否则 101 会被后面的分支"接走"
for score in [101, -1, 100, 80, 79, 60, 59, 0]:
    if score > 100 or score < 0:
        result = "输入错误"
    elif 80 <= score <= 100:
        result = "A"
    elif 60 <= score < 80:
        result = "B"
    else:
        result = "C"
    print("输入", score, "→", result)
运行结果（实测）
输入 101 → 输入错误
输入 -1 → 输入错误
输入 100 → A
输入 80 → A
输入 79 → B
输入 60 → B
输入 59 → C
输入 0 → C
✅ 本节小结：多分支是"从上往下、命中即停"，所以条件必须从最严格排到最宽泛；合法性检查（>100 或 <0）永远放第一个。省略 else 时，可能出现"一个分支都不执行"的情况。

1.6　必做演示：elif 顺序陷阱 学生 100% 会踩

把宽条件写在前面，后面的严格条件就永远没有机会判断。下面把错版和正版并排跑一遍。

错版 vs 正版：同样 6 个分数，两套结果 
for score in [95, 85, 80, 75, 60, 45]:
    # ❌ 错版：宽条件在前，85 分被"及格"先截走
    if score >= 60:
        wrong = "B"
    elif score >= 80:
        wrong = "A"        # 永远到不了这里
    else:
        wrong = "C"

    # ✅ 正版：严格条件在前
    if score >= 80:
        right = "A"
    elif score >= 60:
        right = "B"
    else:
        right = "C"

    print(score, "分 → 错版:", wrong, " 正版:", right)
运行结果（实测）
95 分 → 错版: B  正版: A
85 分 → 错版: B  正版: A
80 分 → 错版: B  正版: A
75 分 → 错版: B  正版: B
60 分 → 错版: B  正版: B
45 分 → 错版: C  正版: C
✅ 本节小结：elif 从上往下互斥匹配，命中就停，所以顺序错了答案就错，而且程序不会报错——这类错误只能靠"边界值测试"抓出来。记住口诀：严格在前，宽泛在后。

1.7　嵌套的分支结构 教材有 · 进度表未点名

多分支能做的事，嵌套分支也能做，但可读性差得多。判断标准很简单：条件是"平级互斥"（A / B / C 选一个）就用 elif；条件有"层次"（先分类、类内再细分）才用嵌套。

嵌套分支：地铁票价（先判断是否学生，再按里程计价） 
is_student = input("是否学生(y/n)：") == "y"
distance = float(input("请输入里程(km)："))

if is_student:
    # 外层 if 的语句块里，又套了一整套 if-elif-else
    if distance <= 6:
        price = 2.0
    elif distance <= 12:
        price = 3.0
    else:
        price = 4.0
    price = price * 0.5          # 学生半价
    note = "学生票五折"
else:
    if distance <= 6:
        price = 2.0
    elif distance <= 12:
        price = 3.0
    else:
        price = 4.0
    note = "全价"

print("票价：%.1f 元（%s）" % (price, note))
运行结果（实测 · 学生 y，里程 10 km）
是否学生(y/n)：y
请输入里程(km)：10
票价：1.5 元（学生票五折）

elif bmi < 28:
    r2 = "过重"

1.8　三元表达式：一句话的二选一 拓展 · 教材未收录

三元表达式（输入 8） 
x = int(input("请输入一个整数："))
result = "偶数" if x % 2 == 0 else "奇数"
print(result)
运行结果（实测）

2.1　什么是循环

教材原话："循环结构是指在一定条件下重复执行某段代码的流程结构。其中，被重复执行的代码块称为循环体，判断是否继续执行的条件称为终止条件。" Python 只有两种循环语句：while 和 for。

✅ 本节小结：循环 = 循环体 + 终止条件。缺了终止条件就是死循环——这是初学者把电脑跑飞的唯一原因。

2.2　while 语句 进度表点名

while 三要素（写在黑板上的那种）：① 设置循环变量并赋初值 → ② 根据循环变量判断条件 → ③ 在循环体中更新循环变量。教材特别强调：循环体中必须有改变循环条件的语句，否则会进入死循环。

用 while 打印 5 次 Hello 
i = 1                # ① 初值
while i <= 5:        # ② 条件
    print("Hello!", i)
    i = i + 1        # ③ 更新（少了这一句就是死循环）

2.6　break 与 continue 进度表点名

AI-2　while = 训练迭代 本章 AI 高潮

AI"训练"的本质：重复同一件事，每次改一点点，直到误差够小。已知 y = 5x，让程序从 w = 1.0 开始自己把 w 学到 5.0。

三要素对上训练：初值 = 参数初始化，条件 = 收敛判据，更新 = 梯度下降 
x = 2.0
y_true = 10.0
w = 1.0            # 循环变量：权重初值（参数初始化）
lr = 0.1           # 学习率
epoch = 0          # 训练轮数计数器

while abs(w * x - y_true) > 0.01:        # 终止条件：误差足够小
    pred = w * x
    w = w - lr * (pred - y_true) * x     # 更新：梯度下降
    epoch += 1
    print("第 %2d 轮：w = %.4f，预测值 = %.4f，误差 = %.4f"
          % (epoch, w, w * x, abs(w * x - y_true)))

print("收敛！共训练 %d 轮，最终 w = %.4f（理论答案 5.0）" % (epoch, w))

AI-3　for = 遍历数据集 + 统计准确率

correct = 0

AI-5　break = 早停（Early Stopping）

验证集准确率连续几轮不涨了就停——再练只会过拟合，还白烧电费。代码上就是一句 break。

连续 3 轮没有进步就提前结束（名义上最多 100 轮） 
x = 2.0
y_true = 10.0
w = 1.0
lr = 0.1
patience = 3             # 容许"连续几轮没有进步"
best_loss = 999
no_improve = 0

for epoch in range(1, 101):               # 名义上最多训练 100 轮
    pred = w * x
    loss = abs(pred - y_true)

    if epoch <= 6:                        # 前 6 轮正常学习
        w = w - lr * (pred - y_true) * x
    # 第 7 轮起模型"学不动了"（真实训练里常见：学习率衰减到 0、
    # 数据重复没有新信息、或已经到精度极限）

    if loss < best_loss - 1e-6:           # 比历史最好还低 → 有进步
        best_loss = loss
        no_improve = 0
    else:                                 # 没进步
        no_improve += 1

    print("第 %2d 轮：loss = %.6f，连续 %d 轮没进步"
          % (epoch, loss, no_improve))

    if no_improve >= patience:
        print(">>> 连续 %d 轮没有进步，触发早停！" % patience)
        break                             # 关键：提前跳出循环

print("实际只训练了 %d 轮，而不是 100 轮" % epoch)

AI-8　嵌套循环 = 注意力矩阵的平方代价

一句话 27 个字 → 每个字都要和所有字算一遍相关度 → 27 × 27 = 729 次；字数翻倍到 54 → 54 × 54 = 2916 次（4 倍）。这就是长文本又慢又贵、按 token 收费的根因。

3 个词、每个词 4 维：手算注意力矩阵 
vectors = [
    [1, 0, 0, 1],   # 词 1
    [0, 1, 1, 0],   # 词 2
    [1, 1, 0, 0],   # 词 3
]
names = ["我", "爱", "你"]

print("注意力矩阵（每个词对每个词的相关度）：")
print("      " + "".join("%6s" % n for n in names))

count = 0
for i in range(len(vectors)):             # 外层：每个词
    row = []
    for j in range(len(vectors)):         # 内层：和每个词算一次
        score = 0
        for k in range(len(vectors[i])):  # 最内层：点积
            score += vectors[i][k] * vectors[j][k]
        row.append(score)
        count += 1
    print("  %2s  " % names[i] + "".join("%6d" % v for v in row))

print("总共执行了 %d 次点积 = 3 x 3" % count)
print("三层嵌套一共 %d 次乘法 = 3 x 3 x 4" % (3 * 3 * 4))
运行结果（实测）

总共执行了 9 次点积 = 3 x 3

✅ 本节小结：嵌套循环 = 每个元素都要和所有元素算一遍，计算量按平方增长。Transformer 的注意力矩阵就是这么算出来的——这就是"长文本贵"的数学原因。
