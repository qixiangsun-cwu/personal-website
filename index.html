怎么用这张表

先看网络 「国内直连」一区打开就能用；「境外服务」一区多数需要自备网络条件，部分还限制注册地区。推荐给学员或同事时，请从上面一区里挑。
再按需求 聊天问答 → 对话助手；查资料、写材料前摸底 → AI 搜索与研究；做图/视频/3D → 创作工具；要接系统、批量调用或比较模型 → 模型 API 聚合平台与排行榜。
零基础上手 点上方「全民级」筛选：免登录或免费额度够用、界面简单，适合第一次接触 AI 的学员。
深入使用 点「专业级」筛选：支持 API、长文本、代码或专业创作工作流，适合科研、开发与商用场景。
